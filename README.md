# tm

`tm` is a tmux helper CLI.

## Install

Install the latest release:

```bash
curl -fsSL https://github.com/edsonjaramillo/tm/releases/latest/download/install.sh | sh
```

For pinned versions, custom install directories, and manual checksum verification, see `INSTALL.md`.

## Release

Release process and artifact details are documented in `RELEASE.md`.

## Usage

Show help:

```bash
tm --help
```

Common commands:

```bash
tm start
tm detach
tm kill --all
tm editor
tm codex
tm claude
tm opencode
tm git
tm dual
tm quads
```
